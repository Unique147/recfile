Recfile - полнофункциональное кроссплатформенное приложение на языке Python с графическим интерфейсом пользователя, реализующее алгоритмы File Carving для поиска и извлечения удаленных файлов из физических накопителей, логических разделов и образов дисков, функционирующих под управлением файловых систем FAT32 и NTFS.

Для обеспечения высокой надежности, масштабируемости и разделения бизнес-логики от интерфейса, архитектура системы декомпозирована на пять независимых модулей:
1.	Модуль GUI: Отвечает за рендеринг элементов интерфейса, обработку пользовательских событий (нажатия кнопок, выбор чекбоксов) и динамическое обновление таблиц данных и прогресс-баров. Передача данных из фоновых потоков осуществляется посредством механизма сигналов PyQt6 (pyqtSignal).
2.	Модуль чтения диска: Реализует безопасное блочное чтение данных с физических дисков (например, PhysicalDrive1) и логических томов с использованием API операционной системы Windows (pywin32) для получения дескриптора устройства с флагами прямого доступа. Поддерживает работу с файлами образов в форматах RAW (.img), DD (.dd) и ISO посредством побайтового считывания в буферную память.
3.	Модуль сигнатурного анализа: Осуществляет алгоритмический поиск байтовых последовательностей в текущем буфере памяти. Производит детекцию начальных смещений файлов и сопоставление их со списками активных расширений, выбранных пользователем.
4.	Модуль восстановления: Извлекает выделенный диапазон байтов из источника, проверяет целостность структуры файла (для сложных контейнеров, таких как ZIP/DOCX) и производит его запись в целевой каталог с генерацией уникального имени, предотвращающего коллизии имен.
5.	Модуль создания образов: Выполняет поблочное копирование всего содержимого выбранного накопителя в файл формата .img, осуществляя контроль ошибок чтения (плохие сектора) и формируя структурированный файл отчета.
